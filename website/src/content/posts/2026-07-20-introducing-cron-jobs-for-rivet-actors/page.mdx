Cron jobs are now built into Rivet Actors. Schedules wake actors on demand and survive sleep, restarts, deploys, and crashes. Use standard five-field expressions with an optional timezone, and inspect recent runs from the Rivet Inspector.

## Show Me The Code

```ts
import { actor, setup } from "rivetkit";

const jobs = actor({
	onCreate: async (c) => {
		await c.cron.set({
			name: "daily-report",
			expression: "0 9 * * *",
			timezone: "America/Los_Angeles",
			action: "runReport",
			maxHistory: 20,
		});

		await c.cron.every({
			name: "refresh-cache",
			intervalMs: 60_000,
			action: "refreshCache",
		});
	},
	actions: {
		runReport: () => {
			console.log("Running daily report");
		},
		refreshCache: () => {
			console.log("Refreshing cache");
		},
		recentRuns: (c) => c.cron.history("daily-report", { limit: 10 }),
	},
});

export const registry = setup({ use: { jobs } });
```

## Schedule At

The existing `schedule.at` API runs an action once at an exact Unix timestamp.

```ts
await c.schedule.at(Date.parse("2026-08-01T09:00:00Z"), "openSale", "summer");
```

## Schedule After

The existing `schedule.after` API runs an action once after a delay in milliseconds.

```ts
await c.schedule.after(30_000, "sendReminder", "reminder-123");
```
