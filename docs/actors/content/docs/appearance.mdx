Actors can be customized with a display name and icon that appear in the Rivet dashboard. This helps identify actors at a glance when managing your application.

## Default Behavior

If no `icon` is specified, actors display the default actor icon, or the workflow icon for [workflow actors](#workflow-actors). If no `name` is specified, the actor's registry key (e.g., `chatRoom`, `gameServer`) is displayed instead.

## Workflow Actors

Actors that set `run` to a [workflow](/workflows/docs) display the workflow icon (`diagram-project`) by default. `options.icon` takes precedence over it:

<CodeSnippet file="examples/docs/actors-appearance/workflow-override.ts" />

The workflow icon is applied through the registry metadata. The native runtime reads `options.name` and `options.icon` directly, so set those explicitly if you need the name or icon to appear everywhere.
