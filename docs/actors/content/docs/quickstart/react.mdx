## Steps

<Steps>
<Step title="Add Rivet Skill to Coding Agent (Optional)">

If you're using an AI coding assistant (like Claude Code, Cursor, Windsurf, etc.), add Rivet skills for enhanced development assistance:

```sh
npx skills add rivet-dev/skills
```

</Step>

<Step title="Create a Project">

Create an empty project and install RivetKit, React, and Vite:

```sh
mkdir my-app
cd my-app
npm init -y
npm pkg set type=module
npm install rivetkit @rivetkit/react react react-dom
npm install -D vite @vitejs/plugin-react tsx
```

The finished project has this layout:

```
my-app/
  backend/index.ts
  frontend/Counter.tsx
  frontend/main.tsx
  index.html
  vite.config.ts
```

</Step>

<Step title="Create Backend Actor and Start Server">

Create your actor registry on the backend and start the server:

<CodeSnippet file="examples/docs/actors-quickstart-react/backend/index.ts" title="backend/index.ts" />

</Step>

<Step title="Create React Frontend">

Create a component that connects to the actor, then mount it:

<CodeGroup workspace>
<CodeSnippet file="examples/docs/actors-quickstart-react/frontend/Counter.tsx" title="frontend/Counter.tsx" />
<CodeSnippet file="examples/docs/actors-quickstart-react/frontend/main.tsx" title="frontend/main.tsx" />
</CodeGroup>

Create the HTML page that loads it:

```html index.html
<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <title>Rivet Counter</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/frontend/main.tsx"></script>
  </body>
</html>
```

For detailed information about the React client API, see the [React Client API Reference](/actors/docs/clients/react).

</Step>

<Step title="Setup Vite Configuration">

Configure Vite for development:

```ts vite.config.ts @nocheck
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'

export default defineConfig({
  plugins: [react()],
  server: {
    port: 5173,
  },
})
```

</Step>

<Step title="Run Your Application">

Start both the backend and frontend:

**Terminal 1**: Start the backend

<CodeGroup>

```sh Node.js
npx tsx --watch backend/index.ts
```

```sh Bun
bun --watch backend/index.ts
```

```sh Deno
deno run --allow-net --allow-read --allow-env --watch backend/index.ts
```

</CodeGroup>

**Terminal 2**: Start the frontend

```sh Frontend
npx vite
```

Open `http://localhost:5173` in your browser. Try opening multiple tabs to see realtime sync in action.

</Step>
