## Steps

<Steps>
<Step title="Add Rivet Skill to Coding Agent (Optional)">

If you're using an AI coding assistant (like Claude Code, Cursor, Windsurf, etc.), add Rivet skills for enhanced development assistance:

```sh
npx skills add rivet-dev/skills
```

</Step>

<Step title="Install Rivet">

Add `rivetkit`, the Effect SDK, and the Effect packages that the SDK uses:

```sh
npm install rivetkit @rivetkit/effect effect @effect/platform-node
```

</Step>

<Step title="Define Your Actor">

An actor has two parts. The contract declares the actor and its actions with [`effect/Schema`](https://effect.website/docs/schema/introduction/). The implementation has the action handlers and runs only on your server.

Put the contract in a file of its own, so your client code can import it:

<CodeSnippet file="examples/docs/actors-quickstart-effect/src/api.ts" title="src/api.ts" />

`Counter.toLayer` makes a layer that registers the implementation. Its first argument is the wake effect. It runs each time the actor wakes and returns the action handlers. Durable data lives in the actor's [SQLite database](/actors/docs/clients/effect#sq-lite-and-migrations). Declare the database with `db`, then yield `Counter.sql` to query it:

<CodeSnippet file="examples/docs/actors-quickstart-effect/src/live.ts" title="src/live.ts" />

</Step>

<Step title="Serve The Registry">

`Registry.serve` starts the actors of a layer. `Registry.layer()` reads the control plane endpoint from the environment:

<CodeSnippet file="examples/docs/actors-quickstart-effect/src/main.ts" title="src/main.ts" />

</Step>

<Step title="Run The Server">

Set `RIVET_RUN_ENGINE=1` to start a local Rivet control plane with the server. RivetKit downloads the control plane binary on the first run and caches it, so there is nothing else to install:

```sh
RIVET_RUN_ENGINE=1 npx tsx --watch src/main.ts
```

Your server now connects to the Rivet control plane on `http://localhost:6420`. Clients connect directly to the control plane on this port.

<Note>
To use a remote control plane, set `RIVET_ENDPOINT=https://...` and do not set `RIVET_RUN_ENGINE`.
</Note>

</Step>

## Feature Support

The Effect SDK (`@rivetkit/effect`) lets you write Rivet Actors as [Effect](https://effect.website) programs. The [Effect page](/actors/docs/clients/effect) is the reference for each feature.

| Feature | Effect API | Reference |
| --- | --- | --- |
| Contract and implementation | `Actor.make`, `MyActor.toLayer` | [Contract And Implementation](/actors/docs/clients/effect#contract-and-implementation) |
| Actions and errors | `Action.make`, `MyActor.of`, `RivetError` | [Actions And Errors](/actors/docs/clients/effect#actions-and-errors) |
| SQLite and migrations | `MyActor.sql`, `onCreate`, `onMigrate` | [SQLite And Migrations](/actors/docs/clients/effect#sq-lite-and-migrations) |
| Forking | `MyActor.client` `fork`, `onFork`, `Actor.CurrentAddress` | [Forking](/actors/docs/clients/effect#forking) |
| Lifecycle and background work | `Actor.sleep`, `Actor.keepAwake`, `Actor.destroy`, `onDestroy` | [Lifecycle And Background Work](/actors/docs/clients/effect#lifecycle-and-background-work) |
| Schedule and cron | `MyActor.schedule`, `MyActor.cron` | [Schedule And Cron](/actors/docs/clients/effect#schedule-and-cron) |
| Workflows | `Workflow.make`, `Workflow.step`, `Workflow.loop`, `onError` | [Workflows](/actors/docs/clients/effect#workflows) |
| Events | `Event.make`, `MyActor.events`, `canSubscribe` | [Connections And Events](/actors/docs/clients/effect#connections-and-events) |
| Connections and auth | `authorize`, `onConnect`, `MyActor.connections` | [Connections And Events](/actors/docs/clients/effect#connections-and-events) |
| Raw HTTP and WebSocket | `http`, `webSocket` | [Raw HTTP And WebSocket](/actors/docs/clients/effect#raw-http-and-web-socket) |
| Client | `MyActor.client`, `Client.layer` | [Calling Actors](/actors/docs/clients/effect#calling-actors) |
| Client events | `handle.connect`, `connection.events` | [Subscribing to Events](/actors/docs/clients/effect#subscribing-to-events) |
| Registry and testing | `Registry.serve`, `Registry.test`, `Registry.health`, `Registry.prometheusMetrics` | [Registry And Testing](/actors/docs/clients/effect#registry-and-testing) |
| Logging and tracing | `Effect.log`, `RivetLogger.layerFromPino` | [Registry And Testing](/actors/docs/clients/effect#registry-and-testing) |
| Raw RivetKit context | `rawRivetkitContext` | [Raw Escape Hatch](/actors/docs/clients/effect#raw-escape-hatch) |

For the features that have no Effect API yet, see [Not Available Yet](/actors/docs/clients/effect#not-available-yet).
