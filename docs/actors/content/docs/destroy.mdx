### Destroy via HTTP

Send a DELETE request to your control plane to destroy an actor. Authenticate with your Rivet token.

<CodeGroup>

```typescript
const actorId = "your-actor-id";
const namespace = "default";
const token = "your-token";

await fetch(`https://rivet.example.com/actors/${actorId}?namespace=${namespace}`, {
  method: "DELETE",
  headers: {
    Authorization: `Bearer ${token}`,
  },
});
```

```bash
curl -X DELETE "https://rivet.example.com/actors/{actorId}?namespace={namespace}" \
  -H "Authorization: Bearer {token}"
```
</CodeGroup>

To find the actor ID, list the actors with that name first:

```bash
curl "https://rivet.example.com/actors?namespace={namespace}&name={actor-name}" \
  -H "Authorization: Bearer {token}"
```

## Accessing Actor After Destroy

Once an actor is destroyed, any subsequent requests to it will fail with an `actor.not_found` error (`{ group: "actor", code: "not_found" }`). The actor's state is permanently deleted.
