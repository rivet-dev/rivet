## Input vs Connection Parameters

Input parameters are different from connection parameters:

- **Input**:
  - Passed when creating the actor instance
  - Use for actor-wide configuration
  - Available in lifecycle hooks
- **Connection parameters**:
  - Passed when connecting to an existing actor
  - Used for connection-specific configuration
  - Available in connection hooks

### Store Input in SQLite

Input is only available in the `onCreate` lifecycle hook. If you need to access input data later (in actions, timers, or other hooks), store it in [SQLite](/actors/docs/sqlite) during creation. This is the recommended pattern because input shapes can evolve over time, and persisting input ensures you always have access to the values the actor was created with:
