### What we'll build

- A `partnerSync` Actor per account that calls a partner API which only accepts allowlisted IPs.
- Workers in a private subnet whose outbound traffic leaves through a NAT gateway with one or two fixed public IPs.
- The list of IPs to send to the partner, and a test that confirms requests arrive from them.
- Retries in the Actor for partner calls that fail while the allowlist is being updated.

### Similar tools

This is the same job as Vercel Static IPs, Heroku Private Spaces, or a QuotaGuard proxy. On Rivet the Actor code runs on workers you deploy, so the fixed IPs come from your own network setup instead of a proxy add-on.
