### What we'll build

- Workers that run your Actors inside your VPC, so their outbound traffic stays on private addresses.
- An `account` Actor that queries a Postgres database and calls an internal API by private IP, with neither exposed to the internet.
- A private link between your clients and Rivet, so calls into your Actors do not cross the public internet.
- Security group and peering rules that allow only the traffic the Actors need.

### Similar tools

This is the same job as AWS PrivateLink, Vercel Secure Compute, Render private networks, or Fly.io private networking. On Rivet the Actors already run on workers you deploy, so placing those workers in your VPC is enough for the outbound side.
