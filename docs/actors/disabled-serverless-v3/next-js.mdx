<Step title="Run the node and Next.js">

Start the node in one terminal, then your Next.js app in another:

```sh
npx tsx --watch src/rivet/node.ts
```

```sh
npm run dev
```

Open your Next.js app and click **Increment**. Open `http://localhost:6420` to inspect the Actor in the local developer tools.

</Step>
</Steps>

## Deploy

Deploy the node as a long-running process. Set its private `RIVET_ENDPOINT` and your Next.js app's `NEXT_PUBLIC_RIVET_ENDPOINT` to the corresponding [production endpoints](/docs/endpoints). Keep the private token on the node.
