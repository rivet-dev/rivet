## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Path Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `pool` | `string` | Yes | Name of the node pool. A DNS label of 1 to 63 lowercase letters, digits and hyphens. |

## Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `namespace` | `string` | No | Name of the namespace to operate in. |

## Responses

### 200

The node pool.

| Field | Type | Description |
| --- | --- | --- |
| `pool` | `object` |  |
| `pool.name` | `string` | Name of the node pool. |
| `pool.drain_on_version_upgrade` | `boolean` | Drain nodes running an older version when a newer version connects. |
| `pool.actor_eviction_delay` | `integer` | Seconds to wait before evicting actors from a draining node. |
| `pool.actor_eviction_period` | `integer` | Seconds over which actors are evicted from a draining node. |
| `pool.actor_eviction_rate` | `number` | Rate at which actors are evicted from a draining node. Must be finite and greater than 0. |
| `pool.metadata` | `any` | Opaque JSON stored with the pool, or `null` when unset. |

```json
{
  "pool": {
    "name": "default",
    "drain_on_version_upgrade": false,
    "actor_eviction_delay": 0,
    "actor_eviction_period": 0,
    "actor_eviction_rate": 0,
    "metadata": null
  }
}
```
