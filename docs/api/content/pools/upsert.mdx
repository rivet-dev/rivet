## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Path Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `pool` | `string` | Yes | Name of the node pool. A DNS label of 1 to 63 lowercase letters, digits and hyphens. |

## Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `namespace` | `string` | No | Name of the namespace to operate in. |

## Request Body

Content type: `application/json`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `drain_on_version_upgrade` | `boolean` | No | Drain nodes running an older version when a newer version connects. |
| `actor_eviction_delay` | `integer` | No | Seconds to wait before evicting actors from a draining node. |
| `actor_eviction_period` | `integer` | No | Seconds over which actors are evicted from a draining node. |
| `actor_eviction_rate` | `number` | No | Rate at which actors are evicted from a draining node. Must be finite and greater than 0. |
| `metadata` | `any` | No | Opaque JSON stored with the pool, at most 16 KiB when serialized. |
