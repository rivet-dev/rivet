## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Path Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `pool` | `string` | Yes | Name of the node pool. A DNS label of 1 to 63 lowercase letters, digits and hyphens. |

## Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `namespace` | `string` | No | Name of the namespace to operate in. |
| `limit` | `integer` | No | Maximum number of results to return. |
| `cursor` | `string` | No | Pagination cursor. Pass the `pagination.cursor` value from the previous response to fetch the next page. |

## Responses

### 200

A page of live nodes.

| Field | Type | Description |
| --- | --- | --- |
| `nodes` | `object[]` |  |
| `nodes[].key` | `string` | Node key, unique within the pool. |
| `nodes[].pool` | `string` | Name of the node pool. |
| `nodes[].namespace` | `string` | Name of the namespace. |
| `nodes[].datacenter` | `string` | Datacenter name. |
| `nodes[].create_ts` | `integer` | When the node connected, in Unix milliseconds. |
| `nodes[].last_ping_ts` | `integer` | When the node last sent a heartbeat, in Unix milliseconds. |
| `nodes[].connected` | `boolean` | Whether the node is connected. |
| `nodes[].stopping` | `boolean` | Whether the node is shutting down. |
| `pagination` | `object` |  |
| `pagination.cursor` | `string \| null` | Cursor for the next page, or `null` when there are no more results. |

{
  "nodes": [
