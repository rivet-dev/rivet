Use this when an actor exposes its own HTTP routes, streams responses (for example Server-Sent Events), or needs to accept non-JSON payloads. The response is whatever the actor's `onRequest` handler returns.

```http
ANY https://api.rivet.dev/gateway/{actor}/request/{path}
```

Accepts `GET`, `POST`, `PUT`, `DELETE`, `PATCH`, `HEAD`, `OPTIONS`.

## Examples

<CodeGroup>

```bash cURL
curl -X POST "https://api.rivet.dev/gateway/counter/request/increment?rvt-namespace=$RIVET_NAMESPACE&rvt-method=getOrCreate&rvt-key=my-counter&rvt-pool=default" \
  -H "x-rivet-token: $RIVET_TOKEN"
```

## Authentication

Send a token in the `x-rivet-token` header, inline in the path as `{actor_id}@{token}`, or in the `rvt-token` query parameter. Use a public token (`pk_`) from browsers and a secret token (`sk_`) from trusted backends. See [Authentication](/docs/api/authentication).

## Path Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `actor` | `string` | Yes | Actor ID, actor ID with an inline token (`{actor_id}@{token}`), or actor name combined with the `rvt-*` query parameters. |
| `path` | `string` | Yes | Path forwarded to the actor. The actor sees a request whose URL path is `/{path}`. |

## Actor Selector

`{actor}` accepts an actor ID, an actor ID with an inline routing token (`{actor_id}@{token}`), or an actor name combined with the `rvt-*` query parameters below. See [Actor Routing](/docs/api/actor-routing) for the full rules.

<Accordion title="rvt-* query parameters">

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `rvt-namespace` | `string` | No | Namespace the actor lives in. Required when `{actor}` is an actor name. |
| `rvt-method` | `string` | No | How to resolve an actor name to an actor. `getOrCreate` requires `rvt-pool`. One of `"get"`, `"getOrCreate"`. |
| `rvt-key` | `string` | No | Actor key. Separate multi-part keys with commas. |
| `rvt-pool` | `string` | No | Pool to create the actor on when `rvt-method=getOrCreate`. RivetKit registers the `default` pool unless configured otherwise. |
| `rvt-runner` | `string` | No | Deprecated alias for `rvt-pool`. |
| `rvt-input` | `string` | No | Base64url-encoded CBOR input passed to `createState` and `onCreate` when `rvt-method=getOrCreate` creates the actor. |
| `rvt-region` | `string` | No | Preferred region when `rvt-method=getOrCreate` creates the actor. |
| `rvt-crash-policy` | `string` | No | Crash policy when `rvt-method=getOrCreate` creates the actor. RivetKit defaults to `sleep`. One of `"restart"`, `"sleep"`, `"destroy"`. |
| `rvt-skip-ready-wait` | `boolean` | No | Return as soon as the actor is resolved instead of waiting for it to be ready. |
| `rvt-token` | `string` | No | Token to authenticate with. Prefer the `x-rivet-token` header or inline path token when possible. |

</Accordion>

## Responses

### 200

The response returned by the actor's `onRequest` handler.
