By default, the request returns after the message is enqueued. Set `wait` to `true` to wait for `message.complete(...)`; `timeout` sets that wait in milliseconds, and a timeout returns `status: "timedOut"` without canceling the queued work.

```http
POST https://api.rivet.dev/gateway/{actor}/queue/{name}
```

## Examples

<CodeGroup>

```bash cURL
curl -X POST "https://api.rivet.dev/gateway/counter/queue/increment?rvt-namespace=$RIVET_NAMESPACE&rvt-method=getOrCreate&rvt-key=my-counter&rvt-pool=default" \
  -H "x-rivet-token: $RIVET_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "body": {
      "amount": 1
    },
    "wait": true,
    "timeout": 5000
  }'
```

## Authentication

Send a token in the `x-rivet-token` header, inline in the path as `{actor_id}@{token}`, or in the `rvt-token` query parameter. Use a public token (`pk_`) from browsers and a secret token (`sk_`) from trusted backends. See [Authentication](/docs/api/authentication).

## Path Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `actor` | `string` | Yes | Actor ID, actor ID with an inline token (`{actor_id}@{token}`), or actor name combined with the `rvt-*` query parameters. |
| `name` | `string` | Yes | Name of the queue message as defined in the actor's `queues` map. |

## Request Body

Content type: `application/json`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `body` | `any` | Yes | Message payload. Any JSON value. |
| `wait` | `boolean` | No | Wait for the actor to complete the message and return its response. |
| `timeout` | `integer` | No | How long to wait for completion, in milliseconds. Only used with wait. |

## Responses

### 200

The message was enqueued, with its completion status when waiting.

| Field | Type | Description |
| --- | --- | --- |
| `status` | `"completed" \| "timedOut"` | Whether the actor completed the message before the timeout. |
| `response` | `any` | Value the actor passed to complete(). Present when status is completed. |

```json
{
  "status": "completed",
  "response": {
    "count": 1
  }
}
```
