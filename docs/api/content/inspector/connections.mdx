## Authentication

Inspector endpoints do not accept namespace tokens. Send the actor's inspector token as a bearer token in the `Authorization` header. Each actor generates its own inspector token on first start and stores it in its KV storage under the single byte `0x03`. Read it through the control plane with `GET /actors/{actor_id}/kv/keys/Aw==?namespace={namespace}` using a namespace token; the response `value` is the token, base64-encoded. The dashboard does this for you.
