SQL executes directly against actor storage. Use bind parameters for values.

```http
POST https://rivet.example.com/gateway/{actor}/inspector/database/execute
```

## Examples

<CodeGroup>

```bash cURL
curl -X POST "https://rivet.example.com/gateway/$ACTOR_ID/inspector/database/execute" \
  -H "Authorization: Bearer $INSPECTOR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "sql": "SELECT * FROM users WHERE id = ?",
    "args": [
      "user-123"
    ]
  }'
```
