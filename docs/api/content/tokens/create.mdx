Each grant names a resource type, a target (`"any"` or a specific `{ "id": ... }`), and the operations it allows. The RivetKit client wraps this as `handle.issueToken()`.

```http
POST https://rivet.example.com/auth/tokens
```

## Examples

<CodeGroup>

```bash cURL
curl -X POST "https://rivet.example.com/auth/tokens" \
  -H "Authorization: Bearer $RIVET_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "namespace": "my-namespace",
    "subject": "user-123",
    "duration": 3600,
    "grants": [
      {
        "resource": "actor_gateway",
        "target": {
          "id": "00000000-0000-0000-0000-000000000000"
        },
        "operations": [
          "read"
        ]
      }
    ]
  }'
```

## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Request Body

Content type: `application/json`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `namespace` | `string` | Yes | Namespace the token is valid in. |
| `duration` | `integer \| null` | No | Lifetime in seconds. Omit for the default lifetime. |
| `subject` | `string \| null` | No | Free-form subject to attach to the token, such as a user ID. |
| `grants` | `object[]` | Yes | Permissions the token carries. |
| `grants[].resource` | `"namespace" \| "actor" \| "node" \| "pool" \| "datacenter" \| "actor_gateway" \| "actor_kv"` | Yes | Resource type the grant applies to. |
| `grants[].target` | `"any" \| object` | Yes | `"any"` for every resource of this type, or `{ "id": "..." }` for one resource. |
| `grants[].operations` | `("read" \| "update" \| "list" \| "create" \| "delete")[]` | Yes | Operations the token may perform on the target. |

## Responses

### 200

The issued token. The response carries `Cache-Control: no-store`.

| Field | Type | Description |
| --- | --- | --- |
| `token` | `string` | The issued token. Treat it as a secret. |
| `issued_ts` | `integer` | When the token was issued, in Unix milliseconds. |
| `expires_ts` | `integer` | When the token expires, in Unix milliseconds. |

```json
{
  "token": "eyJ...",
  "issued_ts": 1700000000000,
  "expires_ts": 1700000000000
}
```

| Field | Type | Description |
| --- | --- | --- |

| `code` | `string` | Error code within the group, for example `not_found`. |
