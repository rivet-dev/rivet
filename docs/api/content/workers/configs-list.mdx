Filter by `variant` to return only `normal` or `serverless` configurations. Use `runner_name` for multiple names because `runner_names` is deprecated.

```http
GET https://api.rivet.dev/runner-configs
```

## Examples

<CodeGroup>

```bash cURL
curl "https://api.rivet.dev/runner-configs?namespace=$RIVET_NAMESPACE" \
  -H "Authorization: Bearer $RIVET_TOKEN"
```

## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `namespace` | `string` | Yes | Name of the namespace to operate in. |
| `limit` | `integer` | No | Maximum number of results to return. |
| `cursor` | `string` | No | Pagination cursor. Pass the `pagination.cursor` value from the previous response to fetch the next page. |
| `variant` | `string` | No | Only return configurations with this variant. One of `"serverless"`, `"normal"`. |
| `runner_names` | `string` | No | Deprecated. Use `runner_name` instead. |
| `runner_name` | `string[]` | No | Only return configurations for these worker names. Repeat the parameter for multiple names. |
