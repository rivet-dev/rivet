The endpoint refreshes the first serverless configuration it finds across datacenters. It fails when the worker name has no serverless configuration.

```http
POST https://api.rivet.dev/runner-configs/{runner_name}/refresh-metadata
```

## Examples

<CodeGroup>

```bash cURL
curl -X POST "https://api.rivet.dev/runner-configs/$RUNNER_NAME/refresh-metadata?namespace=$RIVET_NAMESPACE" \
  -H "Authorization: Bearer $RIVET_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{}'
```

## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Path Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `runner_name` | `string` | Yes | Name of the worker pool whose metadata will be refreshed. |

## Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `namespace` | `string` | Yes | Name of the namespace to operate in. |

## Request Body

Content type: `application/json`.

Send an empty JSON object: `{}`.

## Responses

### 200

The metadata was refreshed.
