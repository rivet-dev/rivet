A failure can occur after the configuration has already been deleted from some datacenters.

```http
DELETE https://api.rivet.dev/runner-configs/{runner_name}
```

## Examples

<CodeGroup>

```bash cURL
curl -X DELETE "https://api.rivet.dev/runner-configs/$RUNNER_NAME?namespace=$RIVET_NAMESPACE" \
  -H "Authorization: Bearer $RIVET_TOKEN"
```

## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Path Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `runner_name` | `string` | Yes | Name of the worker pool whose configuration will be deleted. |

## Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `namespace` | `string` | Yes | Name of the namespace to operate in. |
