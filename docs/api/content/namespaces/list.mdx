## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Query Parameters

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | `string` | No | Only return namespaces with this name. |
| `cursor` | `string` | No | Pagination cursor. Pass the `pagination.cursor` value from the previous response to fetch the next page. |
| `limit` | `integer` | No | Maximum number of results to return. |

## Responses

### 200

Matching namespaces and a cursor for the next page.

| Field | Type | Description |
| --- | --- | --- |
| `namespaces` | `object[]` |  |
| `namespaces[].name` | `string` | Namespace name. |
| `namespaces[].create_ts` | `integer` | When the namespace was created, in Unix milliseconds. |
| `pagination` | `object` |  |
| `pagination.cursor` | `string \| null` | Cursor for the next page, or `null` when there are no more results. |

```json
{
  "namespaces": [
    {
      "name": "my-namespace",
      "create_ts": 1700000000000
    }
  ],
  "pagination": {
    "cursor": null
  }
}
```
