A new namespace is written with status `creating`, or `forking` for a fork, and the call answers once it is `live`, or after 30 seconds with the namespace as it stands; poll `GET /namespaces?name=` until it is `live`. A fork includes every write the parent acknowledged before the call. Pass `wait=settled` to wait a few more seconds after the fork is live, so later parent writes usually stay out of the fork; it does not guarantee it. Namespace names are never reused: an archived or failed name stays listed with its status. Forking is refused for a namespace upgraded from an earlier release until its existing actors have been moved into its volume group (`namespace.not_forkable`). An actor the move could not move after its retries is left in place and listed in the namespace's `skipped` field, by ID, name and key, with their number in `skipped_count` (see `GET /namespaces?name=`). It stays reachable by its ID and its key, so you can read and export its data, and forking stays refused (`namespace.backfill_skipped`, which gives the number of such actors) until each one is destroyed, through `DELETE /actors/{actor_id}` or by the actor itself. Destroying a listed actor is idempotent: repeat it if `skipped_count` did not drop, even once the actor is gone. Access to such actors is removed with the backfill in 3.1, so export and destroy them before upgrading. Forking is also refused for a namespace that is still being created (`namespace.creating`, 503 with `Retry-After`; retry after the hinted delay), forking, archiving or archived (`namespace.pending`, `namespace.archived`), one whose fork failed (`namespace.failed`), one at the lineage depth cap (`namespace.lineage_too_deep`), or one a migration from Rivet v2 is still moving actors into (`namespace.migrating_from_v2`, 409), until the migration ends. A new namespace appears in `GET /namespaces` once its listing entry is written, usually within the call; a lookup by name never waits for it.

```http
POST https://rivet.example.com/namespaces
```

## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Request Body

Content type: `application/json`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `name` | `string` | Yes | Unique name used to identify the namespace. |

## Responses

### 200

The newly created namespace, with its `status` and, for a fork, `forked_from`.

| Field | Type | Description |
| --- | --- | --- |
| `namespace` | `object` | Name of the namespace to operate in. |
| `namespace.name` | `string` | Namespace name. |
| `namespace.create_ts` | `integer` | When the namespace was created, in Unix milliseconds. |
| `namespace.status` | `"creating" \| "forking" \| "live" \| "archiving" \| "archived" \| "failed"` | `creating` while a new namespace's volume group is created, `forking` while a fork's group writes run, `live` once the namespace serves, `archiving` while its nodes stop what they host, `archived` once its storage is closed, for good, and `failed` when a fork was refused after its record was written; the name is then retired. |
| `namespace.forked_from` | `object` | What the namespace was forked from; `null` for a namespace that is not a fork, and while a fork's number is not yet known. |
| `namespace.archived_ts` | `integer \| null` | When the namespace was archived, in Unix milliseconds; `null` unless `archived`. |
| `namespace.skipped` | `object[]` | Legacy: for a namespace upgraded from an earlier release, the actors the move into its volume group could not move, at most 1,000. Each stays reachable by its ID and key until destroyed; destroying it removes it from this list. Empty for every other namespace. Removed with the backfill in 3.1. |
| `namespace.skipped[].actor_id` | `string` | ID of the actor. |
| `namespace.skipped[].name` | `string` | Actor name. |
| `namespace.skipped[].key` | `string \| null` | Actor key in the slash form, or `null` for an actor without one. |
| `namespace.skipped_count` | `integer` | Legacy: how many actors the move could not move and are not destroyed yet, which can exceed the length of `skipped`. Forks and archives of the namespace are refused while it is above zero. Removed with the backfill in 3.1. |

```json
{
  "namespace": {
    "name": "my-namespace",
    "create_ts": 1700000000000,
    "status": "creating",
    "forked_from": null,
    "archived_ts": null,
    "skipped": [],
    "skipped_count": 0
  }
}
```
