## Authentication

Send your namespace token as a bearer token in the `Authorization` header. Every control plane request also requires the `namespace` query parameter. See [Authentication](/docs/api/authentication).

## Request Body

Content type: `application/json`.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `display_name` | `string` | Yes | Human-readable name for the namespace. |
| `name` | `string` | Yes | Unique name used to identify the namespace. |

## Responses
