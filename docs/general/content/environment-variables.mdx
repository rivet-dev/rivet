<Note>
On a Rivet Cloud cluster, Rivet sets the connection and pool variables for you. To set your app's own variables and secrets, see [`rivet cluster env`](/docs/cli#rivet-cluster-env).
</Note>

These variables wire your process to a Rivet control plane. Variables that
configure the RivetKit SDK itself, including logging and storage, are listed in [Environment Variables](/actors/docs/environment-variables)
in the Actors docs.

## Connection

| Environment Variable | Description |
|---------------------|-------------|
| `RIVET_ENDPOINT` | Endpoint URL to connect to Rivet control plane. Supports [URL auth syntax](/docs/connect#url-auth-syntax). |
| `RIVET_TOKEN` | Authentication token for Rivet control plane |
| `RIVET_NAMESPACE` | Namespace to use (default: "default") |

## Nodes

| Environment Variable | Description |
|---------------------|-------------|
| `RIVET_POOL` | Node pool to join (default: "default"). See [Architecture](/docs/architecture#node-pools). |
| `RIVET_NODE_VERSION` | Version number of this node (default: 1). Increase it on every deploy. `RIVET_ENVOY_VERSION` is still read as an older name. See [Versions & Upgrades](/docs/versions#setting-the-version). |

## Local Control Plane

In development, RivetKit starts a local control plane for you. These variables override that behavior.

| Environment Variable | Description |
|---------------------|-------------|
| `RIVET_RUN_ENGINE` | Set to `1` to start a local control plane |
| `RIVET_RUN_ENGINE_HOST` | Host the local control plane binds to. Defaults to `127.0.0.1`. |
| `RIVET_RUN_ENGINE_PORT` | Port the local control plane binds to. Defaults to `6420`. |
| `RIVET_RUN_ENGINE_VERSION` | Version of the local control plane to download |
| `RIVET_RUN_SERVICES` | Services starts by default when RivetKit manages a local Engine. Set to `0` to disable it. |
| `RIVET_SERVICES_BINARY` | Path to a local `rivet-services` binary. |
