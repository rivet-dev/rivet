## Statuses

| Status | Description |
|---|---|
| **Starting** | The Rivet Actor has been created but is not yet accepting connections. |
| **Running** | The Rivet Actor is live and accepting connections. |
| **Sleeping** | The Rivet Actor went to sleep after a period of inactivity. It wakes automatically on the next request. |
| **Pending** | The Rivet Actor is waiting for a node. This happens when no node in its node pool is connected. See [Troubleshooting](/actors/docs/troubleshooting#actor-status-is-pending) for common causes. |
| **Crashed** | The Rivet Actor failed to start or hit a fatal error. See [Troubleshooting](/actors/docs/troubleshooting#actor-status-is-crashed) for common failure reasons. |
| **Destroyed** | The Rivet Actor was destroyed. |
