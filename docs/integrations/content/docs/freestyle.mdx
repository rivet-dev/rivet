[Freestyle](https://freestyle.sh) runs Firecracker VMs from snapshots and pauses them when idle. Through `@rivet-dev/sandbox-adapter`, each Actor creates a Freestyle VM, runs commands and uses files in it, pauses it while the Actor sleeps, and deletes it when the Actor is destroyed.

## Quickstart

<Steps>

<Step title="Install">

```sh
npm install rivetkit @rivet-dev/sandbox-adapter freestyle
```

</Step>

<Step title="Configure Freestyle">

Create an API key in the [Freestyle dashboard](https://admin.freestyle.sh) and put it in `.env`. It stays on the node and never enters the VM.

```sh title=".env"
FREESTYLE_API_KEY=
```

</Step>

<Step title="Define the Actor">

Each `build` Actor owns one Freestyle VM. A VM has no network access until a `firewall` rule allows it, so `create` is required. The first `run`, `saveFile`, or `readFile` creates the VM; later calls connect to the same one.

## Options

| Option | Description |
| --- | --- |
| `create` | Options for Freestyle's `vms.create`, or a function that receives the Actor context and returns them. Required, because `firewall` is required. |
| `client` | A Freestyle client. Defaults to `new Freestyle()`, which reads `FREESTYLE_API_KEY`. |
| `cwd` | Working directory inside the VM. Created when the Actor connects. Defaults to `/workspace`. |

Commands run as `root` through Python 3, so the snapshot must include it. Every `freestyle/ubuntu*` snapshot does. `suspend` pauses the VM while the Actor sleeps, and `destroy` deletes it.

The `Sandbox` API, lifecycle, and the other providers are in the [sandbox adapter guide](/guides/sandbox-adapter).
